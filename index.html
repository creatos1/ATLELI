Modo de uso

Un ritual de segundos.

Aplicalo antes de salir, al llegar a la oficina, despues de tocar superficies o cuando quieras refrescar tus manos con aroma botanico.

  1. Agita bien antes de usar. Activa la mezcla y prepara el spray para una aplicacion uniforme.
  2. Aplica en las manos. Usa una cantidad suficiente para cubrir palmas, dedos y dorso.
  3. Distribuye hasta que seque. Frota suavemente hasta sentir las manos limpias y protegidas.
  4. Disfruta el aroma. Elige menta para energia o lavanda para una pausa tranquila.
